# Data Card

## FinQA

- 来源：`czyssrs/FinQA` 官方公开仓库；
- 用途：检索、数值推理和执行结果的标准化评估；
- 关键字段：`question`、`gold_inds`、`program`、`exe_ans`、表格和财报文本；
- 隔离规则：训练集用于训练或增强，验证集用于选择方案，测试集只用于最终只读评测；
- 已知限制：数据主要为英文财务报告，不能直接代表中文企业财报或真实生产分布。

处理过程保留表头、行名、年份、单位、正负号和证据 ID。当前版本不将整份财报拼接为单一上下文。

## 业务演示集

`data/business_eval/cases.json` 为合成示例，不含个人信息、商业秘密或真实企业敏感数据。包括三类正常计算任务和一个必须拒答的缺证据任务。
